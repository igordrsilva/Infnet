# Teste de Performance 1 - Desenvolvimento Front-End com Python (com Streamlit)

## Objetivo do trabalho
Esse é o nosso primeiro Teste de Performance. Para a realização dos exercícios abaixo, utilizaremos a base de dados "Most Streamed Spotify Songs 2024". Esta base de dados apresenta uma compilação abrangente das músicas mais reproduzidas no Spotify em 2024. Ela oferece insights detalhados sobre os atributos de cada faixa, sua popularidade e presença em diversas plataformas musicais. A base de dados inclui informações como: nome da música, artista, data de lançamento, ISRC, estatísticas de streaming e presença em plataformas como YouTube e Tik Tok. Esta fonte de dados é valiosa para analistas de música, entusiastas e profissionais da indústria.

Você pode obter a base de dados neste https://www.kaggle.com/datasets/nelgiriyewithana/most-streamed-spotify-songs-2024. Utilize os dados da maneira mais criativa e informativa que você pensar!
